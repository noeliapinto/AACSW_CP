# Complejidad ciclomática

Ejemplos de código para analizar utilizando ESLint Playground.

## Actividad 1

1. Copiar el contenido de `calcularDescuento.js`.
2. Ingresar a https://eslint.org/play/
3. Pegar el código.
4. Identificar la complejidad ciclomática.
5. Reconocer las estructuras que incrementan la complejidad.
6. Refactorizar el código para que ninguna función supere una complejidad de 5.
7. Comparar los resultados antes y después de la refactorización.
